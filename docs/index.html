Build it

Clone, generate, run

git clone https://github.com/Nano-AI/lake-day.git
cd lake-day
brew install xcodegen && xcodegen
open LakeDay.xcodeproj

The Xcode project is generated from project.yml, so it isn’t checked in. Tests cover the rating curves, the safety hard-zero and the feed parsers.

Lake Day republishes data from King County, the National Weather Service and Open-Meteo. It is a personal project, it can be wrong, and it is not a substitute for the signage posted at the beach. If the sign and the app disagree, believe the sign.
